# Student Result Management System

A simple Student Result Management System made using Python, Tkinter and Excel.

## Features

- Add student details and marks
- Calculate total marks and percentage
- Check result using Roll No.
- Show all student results
- Store student data in an Excel file

## Technologies Used

- Python
- Tkinter
- OpenPyXL
- Excel

1. Install Python.
